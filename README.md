# Eden

Playable **Aetherion** demo set on the world of **Eden**.

The story bible, Circuit Ink plates, people, gods, and continents live in
[Darkstone007/Aetherion](https://github.com/Darkstone007/Aetherion). This repo is the game:
walk the hour, keep a table or file the form, open Kima / Anima / Dual Pulse, and loop.

## Names

| | |
|---|---|
| Universe / game | **Aetherion** |
| World | **Eden** |
| House style | **Circuit Ink** (Arcane method, Edgerunners night) |
| Anima | cyan `#00E8D5` — soul, lattice |
| Kima | magenta `#FF2E78` — body, forge, wound |

Seven inhabited continents, unchanged from the bible:

Elysara · Xihuang · Nordheim · Tezcal · Abyssara · Vindraeth · Caelus Prime

## Play

- **WASD** move (A left, D right on screen)
- **Mouse** aim
- **J / click** Kima (body strike)
- **K / right-click** Anima (soul bolt)
- **L** Dual Pulse (both wells — the System hates this)
- **Shift** step
- **E** talk, doors, continent nodes
- **Auto-Demo** walks a recordable hour
- Title screen **Trailer** downloads `Aetherion-Eden-Trailer.mp4`

Awakening writes Vigor / Arcanus / Aequalis. Oath vs Control are meters, not a sermon. Fracture Hour resets the body, not the memory.
