# Eden

Playable **Aetherion** demo set on the world of **Eden**.

## Play now

**[https://darkstone007.github.io/eden/](https://darkstone007.github.io/eden/)**

That link *is* the game — title screen, Fracture Hour loop, Dual Flow combat, seven continents. This README is only the source index.

Story bible, Circuit Ink plates, people, gods, and continents live in [Darkstone007/Aetherion](https://github.com/Darkstone007/Aetherion). This repo is the game: walk the hour, keep a table or file the form, open Kima / Anima / Dual Pulse, and loop.

Elysara · Xihuang · Nordheim · Tezcal · Abyssara · Vindraeth · Caelus Prime

## Controls

- **Play Hour** — cinematic chronicle on the original plates
- **Auto-Demo** — walks a recordable hour
- **Codex** — people met, continents walked, memories that persist
- **Trailer** — downloads `Aetherion-Eden-Trailer.mp4`
- Combat: **J** Kima (body), **K** Anima (soul), **L** Dual Pulse, **Shift** Step
- Choices: click, or **1–4**
- Oath vs Control are meters, not a sermon
- Fracture Hour resets the body, not the memory

Awakening writes Vigor / Arcanus / Aequalis. Caelus Prime opens after two continents beyond Elysara.
